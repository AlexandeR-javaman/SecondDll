1. Плагин изменяет масштаб переменных чертежа (масштаб размеров и масштаб выносок) либо применяет требуемый масштаб ко всем выбранным размерам, мультивыноскам и блокам оформления.
2. Пользовательское меню предлагает выбор изменять переменные чертежа или масштабы выбранных объектов.
3. Выбор изменяемых объектов фильтруется автоматически, в дополнительных параметрах можно выбирать, к каким объектам применять изменения: все размеры, все мультивыноски, блоки на слое оформления. Слой с блоками оформления тоже можно указывать
